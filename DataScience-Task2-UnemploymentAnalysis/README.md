# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends across different states in India using Python. The analysis focuses on identifying regional differences, monthly trends, and the impact of the COVID-19 pandemic on unemployment rates.

## Objectives

- Explore unemployment data using Exploratory Data Analysis (EDA).
- Compare unemployment rates across Indian states.
- Analyze monthly unemployment trends.
- Visualize unemployment changes in selected states.
- Compare unemployment before and after COVID-19.
- Study correlations between unemployment, employment, and labour participation.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (Google Colab)

## Dataset

Source:
Kaggle - Unemployment in India Dataset

## Project Structure

- Data Cleaning
- Exploratory Data Analysis
- Regional Analysis
- Monthly Trend Analysis
- Time Series Visualization
- Correlation Analysis
- Pre-COVID vs Post-COVID Comparison
- Conclusion

## Key Findings

- Tripura recorded the highest average unemployment rate.
- Meghalaya recorded the lowest average unemployment rate.
- April 2020 showed the highest average unemployment rate.
- COVID-19 significantly increased unemployment across India.
- No strong linear correlation was found between unemployment, employment, and labour participation rates.
